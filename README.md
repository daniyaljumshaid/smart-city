# AI-based Smart City Management System

Role-driven Smart City Flutter application with AI-assisted civic issue handling.

## User Roles

1. Citizen
2. Government Officer
3. Admin

## Core Modules

1. Complaint and issue reporting
2. AI issue classification and urgency scoring
3. Real-time tracking dashboard with ETA and notifications
4. Emergency mode with SOS and live location sharing
5. City data analytics dashboard
6. AI city insights and predictive trends
7. Community section (polls, feedback, suggestions, announcements)

## Primary Workflow

1. Citizen logs in and submits complaint with description, location, and photo.
2. AI classifies category, priority, urgency score, and department assignment.
3. Government Officer receives assigned task and updates status with evidence.
4. Citizen tracks progress, ETA, and receives notifications.
5. Admin monitors analytics, hotspots, and predictive city insights.
